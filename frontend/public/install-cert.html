Install Local Certificate

Install this certificate so your phone trusts the Shadow Attendance local HTTPS server.

Download certificate (.crt) Download certificate (.pem)

iPhone

  1. Tap Download certificate.
  2. Open Settings and install the downloaded profile.
  3. Go to General > About > Certificate Trust Settings.
  4. Enable full trust for the mkcert certificate.

Android

  1. Tap Download certificate.
  2. Install it as a CA certificate or VPN/app certificate.
  3. Use your lock screen PIN if Android asks.
