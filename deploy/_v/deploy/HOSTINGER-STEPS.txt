Hostinger backend deploy (after uploading the zip)
==================================================

1. Upload & extract
   - hPanel -> File Manager -> your site root (e.g. domains/api.yourdomain.com)
   - Upload backend-hostinger-*.zip and extract
   - You must see TWO folders: backend/  and  deploy/
   - WRONG: files named backend/app with backslashes in names - delete all, use latest zip
   - Document root must point to: backend/public

2. .env on server
   - Copy deploy/.env.hostinger from the zip to .env (one folder ABOVE backend/)
   - Edit APP_URL and SANCTUM_STATEFUL_DOMAINS
   - Images use Cloudflare R2 (R2_* vars in .env.hostinger)

3. SSH or Hostinger Terminal (inside backend folder):
   composer install --no-dev --optimize-autoloader
   php artisan storage:link
   php artisan migrate --force
   php artisan config:cache
   php artisan route:cache

4. Permissions (if 500 errors):
   chmod -R 775 storage bootstrap/cache

5. Vercel frontend env:
   VITE_API_URL=https://api.YOUR-DOMAIN.com/api
   Then redeploy Vercel.

Updates later
-------------
- Change code locally -> git push (Vercel auto-updates frontend)
- Run .\deploy-hostinger.ps1 again -> upload new zip -> SSH:
    composer install --no-dev
    php artisan migrate --force
    php artisan config:cache
    php artisan route:cache
